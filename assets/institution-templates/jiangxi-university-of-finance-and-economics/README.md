# Jiangxi University of Finance and Economics master's thesis template

This optional package combines the bundled JUFE thesis document with a configurable figure and three-line-table preset. It is never the global Econfigure Skill default.

## Use

Select it only when the user explicitly says the target document is a Jiangxi University of Finance and Economics master's thesis, supplies the bundled template, or asks to use this package. Read `template.yaml`, apply its figure or table fields, and let a newer user-supplied document override conflicting values.

The bundled `jufe-master-thesis-template.doc` is preserved in its original legacy Word format. Its SHA-256 value is recorded in `template.yaml` so users can detect accidental changes.

## Figure and table settings

- Figure content: Chinese SimSun and Latin Times New Roman, 10.5 pt.
- Chinese and English figure captions: 12 pt, centered, below the figure.
- Table body: Chinese SimSun and Latin Times New Roman, 10.5 pt.
- Table title: 12 pt, centered, above the table.
- Three-line tables have no vertical rules. The packaged rule profile uses 1.5 pt / 0.75 pt / 1.5 pt for top, header, and bottom rules.
- Figure and table numbering follows the chapter-number pattern.
- Econfigure Skill still exports the figure itself as a 600 dpi PNG; captions remain in the thesis document.

The public JUFE graduate-school guidance is linked in `template.yaml`. Requirements can change, so compare this package with the latest institution or department document before final submission.

## Evidence and scope

The bundled document supports A4 pages, 12 pt centered captions, Chinese SimSun / Latin Times New Roman body text, and three-line table structure. The 10.5 pt figure/table content and 1.5 / 0.75 / 1.5 pt rule weights are package conventions, not independently verified current school requirements. The effective document version and permission to redistribute the original Word file have not been confirmed. Use the current school document to resolve conflicts.
